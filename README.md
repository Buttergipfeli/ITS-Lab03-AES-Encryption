# Lab03 - ITS

## Task

### Objective

Write a program in the language of your choice that can encrypt and decrypt a file. Use AES as the encryption algorithm. Select a suitable library that allows you to use the AES functions directly.

### Submission

**You will receive 2 lab credits if:**

- you can enter the key via a user interface
- you can choose between the different AES encryption modes
- subsequent encryptions of the same file lead to different encrypted files
- a modification of the data in transit would be detected during decryption
- you can encrypt a message on one computer, transfer it to another computer and decrypt it there
- you demonstrate your program to your lecturer, explain how it works and reflect on how AI assisted you with your assignment
